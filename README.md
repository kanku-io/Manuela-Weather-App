Manuela Weather App

A clean, dark-themed weather app built with vanilla HTML, CSS, and JavaScript using the OpenWeatherMap API.

Features

- Current weather conditions for any city
- Hourly forecast for the next 24 hours
- 5-day forecast with temperature range bars
- City autocomplete, suggestions appear after 3 characters
- Switch between Celsius and Fahrenheit instantly
- Humidity, wind speed and direction, feels like, and cloud cover stats
- Fully responsive across desktop, tablet, and mobile



Guide to use:

- Type a city name into the search bar
- After 3 characters, a dropdown will suggest matching cities
- Click a suggestion or press Enter to search
- Use the °C / °F buttons in the top right to switch units

## API

This app uses three OpenWeatherMap endpoints:

- `api.openweathermap.org/data/2.5/weather` — current conditions
- `api.openweathermap.org/data/2.5/forecast` — hourly and 5-day forecast
- `api.openweathermap.org/geo/1.0/direct` — city autocomplete

All three are available on the free tier.
